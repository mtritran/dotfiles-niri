# 🌌 My Niri + Noctalia Dotfiles

Clean, minimalist, and production-ready configuration for **Niri Window Manager** and **Noctalia Shell** on Arch / CachyOS Linux.

## 📦 What's Included

* **Niri WM** (`config/niri`): Custom keybindings, layout gaps, animations.
* **Noctalia Shell** (`config/noctalia`): Tokyo Night theme, bar widgets, Control Center settings.
* **Gammastep** (`config/gammastep`): Custom screen color temperature configuration.
* **Fuzzel** (`config/fuzzel`): Fast Wayland application launcher & picker menu.
* **Alacritty & Fish** (`config/alacritty`, `config/fish`): Terminal & shell configurations.
* **Scripts** (`local/bin`): Custom helper scripts like `gammastep-picker`.

## ⌨️ Useful Shortcuts

| Shortcut | Action |
| --- | --- |
| `Super + Space` | Open Noctalia App Launcher |
| `Super + Shift + W` | Open Noctalia Control Center |
| `Super + Shift + Q` | Open Session Menu (Power/Lock) |
| `Super + Alt + L` | Lock Screen |
| `Super + Shift + G` | Open Gammastep Screen Color Picker |
| `Super + F` | Maximize window (keeps taskbar visible) |
| `Super + Shift + F` | Fullscreen window (covers taskbar) |
